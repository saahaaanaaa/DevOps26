# Lab 3 - MLflow Experiment Tracking with DagsHub

## Objective
Perform regression on the Boston Housing dataset using three machine learning models and track experiments using MLflow integrated with DagsHub.

## Dataset
- Boston Housing Dataset (`BostonHousing.csv`)

## Models Implemented
- Linear Regression
- Random Forest Regressor
- XGBoost Regressor

## Evaluation Metrics
The following metrics were logged for each model:
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Experiment Tracking
Experiments were tracked using **MLflow** and visualized on **DagsHub**.
